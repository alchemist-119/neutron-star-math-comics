# 🌟 這個 Repository 在做什麼？

這裡收藏哥哥「中子星」的數學學習思考漫畫。

我們不急著背公式或看到關鍵字就套規則，而是先問：

- 為什麼這個規則成立？
- 題目的未知量究竟是什麼？
- 數字裡藏著什麼結構？
- 如果忘記公式，能不能自己重新推回來？
- 原本的想法哪裡需要檢查與修正？

每一篇漫畫都盡量保留完整的思考路徑：

> **觀察 → 假設 → 建模 → 推理 → 檢查 → 修正**

我們希望學到的不只是一道題目的答案，而是一套可以帶到新問題裡的數學思考方法。

# ➗ 第四單元：分數除法

分數除法不只是一條「乘以倒數」的計算規則。本單元重新追問除法在問什麼，從平均分與包含除出發，理解共同單位、通分、倒數、商的大小、數量關係與驗算。

## 4-1｜同一個除法，為什麼可以代表兩種問題？

同一算式可問「每份多少」或「共有幾份」；算式相同，但未知量不同。

![中子星分數除法 4-1｜同一個除法，為什麼可以代表兩種問題？](04-01-two-division-models.png)

## 4-2｜分數也可以是「一份的大小」嗎？

把分數看成一份的大小，回到包含除的原始意義。

![中子星分數除法 4-2｜分數也可以是「一份的大小」嗎？](04-02-fraction-as-unit-size.png)

## 4-3｜同分母相除，分母真的消失了嗎？

兩邊使用相同單位時，只需比較各自包含多少個共同單位。

![中子星分數除法 4-3｜同分母相除，分母真的消失了嗎？](04-03-dividing-like-denominators.png)

## 4-4｜兩邊都只有一份，為什麼不能直接相比？

份數相同不代表大小相同；真正的困難是測量單位不同。

![中子星分數除法 4-4｜兩邊都只有一份，為什麼不能直接相比？](04-04-unlike-fraction-units.png)

## 4-5｜通分到底是在做什麼？

通分是把不同刻度換成共同單位，讓兩邊能用同一把尺比較。

![中子星分數除法 4-5｜通分到底是在做什麼？](04-05-common-denominator-as-unit.png)

## 4-6｜為什麼除以分數會變成乘倒數？

把除數縮放成 1，並讓被除數同乘相同倍數，保持比較關係不變。

![中子星分數除法 4-6｜為什麼除以分數會變成乘倒數？](04-06-why-dividing-multiplies-reciprocal.png)

## 4-7｜倒數不是上下翻面，那到底是什麼？

倒數是和原數相乘會得到 1 的數；上下翻面只是外觀。

![中子星分數除法 4-7｜倒數不是上下翻面，那到底是什麼？](04-07-meaning-of-reciprocal.png)

## 4-8｜0 為什麼沒有倒數？

任何數乘以 0 都不可能得到 1，所以 0 沒有倒數，也不能作除數。

![中子星分數除法 4-8｜0 為什麼沒有倒數？](04-08-zero-has-no-reciprocal.png)

## 4-9｜除法一定會讓數字變小嗎？

用反例修正模型：商可能變大、變小或不變，要看除數和 1 的關係。

![中子星分數除法 4-9｜除法一定會讓數字變小嗎？](04-09-division-does-not-always-shrink.png)

## 4-10｜為什麼除數越小，商反而可能越大？

總量固定時，每份越小，能分出的份數就越多。

![中子星分數除法 4-10｜為什麼除數越小，商反而可能越大？](04-10-smaller-divisor-larger-quotient.png)

## 4-11｜被除數、除數和商誰控制誰？

總量、每份量與份數會一起變動；先固定條件，才能判斷變化方向。

![中子星分數除法 4-11｜被除數、除數和商誰控制誰？](04-11-division-quantity-relationships.png)

## 4-12｜看到「每」就一定要除嗎？

關鍵字不能決定運算；先辨認已知量、未知量與數量關係。

![中子星分數除法 4-12｜看到「每」就一定要除嗎？](04-12-each-does-not-always-mean-divide.png)

## 4-13｜同樣三個數字，為什麼可以寫出不同題目？

未知量的位置不同，就會形成求份數、求總量或求每份量的不同問題。

![中子星分數除法 4-13｜同樣三個數字，為什麼可以寫出不同題目？](04-13-same-numbers-different-problems.png)

## 4-14｜分數除法算完，怎麼知道答案合理？

用乘回去、估大小與畫單位圖三種不同證據挑戰答案。

## 4-15｜忘記誰要顛倒，怎麼辦？

從共同單位或把除數變成 1 重新推回規則，不必依賴記憶口訣。
