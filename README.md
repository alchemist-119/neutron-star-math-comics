# 🌟 這個 Repository 在做什麼？

這裡收藏哥哥「中子星」的數學學習思考漫畫。我們不急著背公式，而是保留完整的思考路徑：

> **觀察 → 假設 → 建模 → 推理 → 檢查 → 修正**

希望學到的不只是一道題目的答案，而是一套可以帶到新問題裡的數學思考方法。
